# Basic Data Structures Implementation in C++

## 📌 Overview
This project demonstrates the implementation of fundamental data structures in C++ including singly linked list, doubly linked list, stack, and queue. It also includes basic file handling operations and algorithmic problem solving.

## ⚙️ Features
- Singly Linked List (insert, display)
- Doubly Linked List (forward & backward traversal)
- Stack (LIFO implementation)
- Queue (FIFO implementation)
- File handling (read and write operations)

## 🛠️ Technologies Used
- C++
- Standard Library (without STL containers for learning purposes)
  
## 🚀 Future Improvements
- Trees (Binary Tree, BST)
- Graph algorithms (BFS, DFS)
- STL-based optimized implementations
- Menu-driven interactive program
  
## 📖 Topics Covered
- Dynamic memory allocation
- Pointer manipulation
- Linear data structures
- File I/O operations
- Basic algorithmic design
